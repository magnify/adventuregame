# Girl reference layers

Cut from `art/reference/girl-sheet.png` on the reference image's unchanged 1024 × 1536 canvas. Stack `arm-back.png`, `leg-back.png`, `leg-front.png`, `body.png`, `arm-front.png`, then `head.png` in that order. `head-blink.png` replaces `head.png` for a blink; it has the same canvas and silhouette.

The visible paper pixels are copied from the sheet. Rounded shoulder, hip and neck tabs continue underneath their covering layers so small rotations do not expose a gap. `joints.json` gives matching body sockets and part pins in reference pixel coordinates. `stacked.png` is the actual layer composite for review.
